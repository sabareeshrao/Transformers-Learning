## Engineering problem

We already know basic Python lists. Machine-learning libraries need a data structure that can participate in fast numerical operations. Today we only learn the first bridge from Python into PyTorch: converting a Python list into a tensor.

**Decision:**

Take one familiar Python list, convert it to a PyTorch tensor, print the result, and stop there.

## Code

```python
import torch

# Day 1.1: TL-001 create our first PyTorch tensor from familiar Python numbers.
numbers = [10, 20, 30]
tensor = torch.tensor(numbers)

# Day 1.2: TL-001 print the tensor so we can verify what PyTorch created.
print(tensor)
```

## Explanation — Telugu in English Font

