# Transformers Learning

A 600-day hands-on journey toward understanding and rebuilding the core ideas behind Hugging Face Transformers.

Reference repository: `huggingface/transformers`

## Learning rule

- Basic Python is assumed.
- One small technical idea per day.
- Every day includes a Telugu-in-English-font engineering discussion.
- Source code keeps `Day X.Y` comments.
- Every completed day gets one primary learning commit and remote verification.
- We do not copy the finished Transformers library wholesale.
